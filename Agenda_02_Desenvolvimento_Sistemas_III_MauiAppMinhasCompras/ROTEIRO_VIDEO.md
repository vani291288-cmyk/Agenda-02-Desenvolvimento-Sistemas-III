# Roteiro para o vídeo da Agenda 02

Grave a tela do celular/emulador e, se possível, também mostre rapidamente o Visual Studio.

## Sequência sugerida
1. Abra o aplicativo **Minhas Compras**.
2. Mostre a tela de cadastro.
3. Cadastre um produto, por exemplo:
   - Descrição: Cadeira de praia
   - Quantidade: 2
   - Preço: 50,00
4. Mostre o produto aparecendo na lista.
5. Cadastre outro produto.
6. Feche e abra novamente o aplicativo para demonstrar que os dados continuam armazenados no SQLite.
7. Use o campo de pesquisa e digite parte da descrição para demonstrar a busca.
8. Finalize mostrando rapidamente no Visual Studio os arquivos:
   - `Models/Produto.cs`
   - `Helpers/SQLiteDatabaseHelper.cs`
   - `Data/Database.cs`
   - `MainPage.xaml`
   - `MainPage.xaml.cs`

## Fala curta sugerida
"Este é o projeto desenvolvido para a Agenda 02 de Desenvolvimento de Sistemas III. O aplicativo utiliza .NET MAUI e SQLite para persistência de dados. Nesta etapa foram implementadas as operações de inserção e leitura, além da busca por descrição. Também foram preparados os métodos de atualização e exclusão no helper do banco de dados. Agora vou demonstrar o cadastro, a listagem e a pesquisa dos produtos."

## O que aparece no vídeo
- Código sendo criado ou editado.
- Aplicativo funcionando.
- Produto sendo cadastrado.
- Lista sendo atualizada.
- Pesquisa funcionando.
- Persistência após reabrir o aplicativo.
